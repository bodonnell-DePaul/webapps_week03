1. The finished deliverable
This is one reference example of Evidence Before Action. Your layout can differ. What matters is a clear, trustworthy workflow: import, explore, and export. The handout and data contract define the requirements.

2. Start with a local CSV
Start with a labeled file picker. Download stays disabled until data loads. Do not add login, an application backend, or saved browser data; a static dev or preview server is fine.

3. A clear import report
Choose campus tickets from your computer. The app identifies the active file and reports accepted and rejected records. These records are synthetic, not real campus data.

4. One consistent analysis
The summary shows matching tickets, open tickets, overdue work, known hours, and estimate coverage. The zone table uses the same matching records and fixed reference date.

5. Combine the controls
Filters work together. Selecting South and Open updates the table and every summary together. This is not a static dashboard with independently hardcoded numbers.

6. Unknown estimates are not zero
Here, only fourteen of thirty-three open tickets have estimates. Seventy-two known hours is not the total workload. Missing estimates must remain visible, not become zero.

7. Search also narrows the same records
Text search is case insensitive and combines with the zone and status filters. Search ticket identifiers or summaries; all displayed metrics must follow those same matches.

8. Sorting changes order, not totals
Switch between oldest opening first and highest estimate first. Sorting changes order, not membership or totals. In descending estimate order, unknown estimates belong last.

9. Fifty rows per page
Resetting filters restores the full dataset and preserves the sort. Previous and Next show fifty rows at a time. Summaries still describe all matching records.

10. No matches is a normal state
A search with no matches should show a useful empty message and a way to reset filters. Zero results must not produce broken controls or invalid numbers.

11. A failed import must preserve current work
A file with an invalid header produces a clear error, without replacing the active dataset. Show the failed attempt separately from the file that is still being analyzed.

12. Mixed-quality files are explained
This edge-case file contains both usable and rejected records. Load the valid subset and explain the rejected records. Do not silently fix or discard troublesome data.

13. Actionable record-level feedback
Each rejection identifies a logical record and a reason. Here you can see an impossible date and a duplicate. An invalid earlier record must not reserve its identifier.

14. Preserve data as text
Quoted commas and newlines remain part of a field. Markup-looking summaries are displayed literally. Unknown and zero estimates remain distinct in the actual records, too.

15. Download the whole matching set
Now return to the full dataset and download the analysis while viewing page two. The file must contain all two hundred forty matches, not just fifty visible rows.

16. The real exported file / excerpt
The JSON records the source, filters, sort, metrics, zone summaries, and matching rows. This excerpt is a video aid; an in-app JSON viewer is not required.

17. Works without data services
After the app assets load, turn networking off. Local file import, filtering, and export must still work. This does not require an offline reload or a service worker.

18. Usable on a narrow screen and by keyboard
At a narrow width, controls stack and tables scroll within their own region. Keyboard focus must stay visible. Also check contrast and two hundred percent browser zoom.

19. The app is only part of the submission
Submit source, lockfile, setup instructions, three tests with fixtures, analysis JSON, and a screenshot. Limit EVIDENCE.md to 800 words, including a 100-150 word recommendation. Small numeric/check tables do not count toward that limit.

20. Use Copilot. Own the reasoning.
Make your independent prediction before implementation. Keep one meaningful Copilot decision, a real ten-minute peer tryout, and the five-minute individual check. This video does not replace those human activities.
